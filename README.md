# tiny-linkrot

A tiny CLI that scans a directory of Markdown files, finds HTTP(S) links,
checks each one for a valid response, and reports broken or redirected
links grouped by source file.

This repo is the live demo of the [samospec](https://github.com/NikolayS/samospec)
workflow: an AI-authored, multi-round-reviewed specification captured in git,
produced without a single human-typed line of the spec.

## Status

- Spec: in progress — see the `samospec/linkrot` branch
- Implementation: not started (spec first)
